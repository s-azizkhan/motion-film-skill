# Proven formats (from 602 Opus 5.5 video prompts that people shared)

Use in the hook lab: pick the format that fits the brief, then run `python3 search.py "<topic> <format words>"`
for 5–8 real prompts in that shape to steal structure from (never their content). Each format names its carry.

| # | Format | Shape | Carry / why it holds |
|---|---|---|---|
| 1 | **One rule, made visible** | One constraint drives the whole film: every note is a visible collision, 1 marble = 1 million people, every clink synced | Cause → effect, every beat triggers the next. SFX *are* the content |
| 2 | **Never-stop zoom** | Start at a desk and don't stop until one atom (or the reverse: one pixel → a city) | One camera move, one world; scale is the story |
| 3 | **The reveal twist** | Viewer thinks it's X for 25 s; the last frames show it was Y (tiles were building the ad; the timeline was one sentence) | Everything is the final frame's material |
| 4 | **Year slam timeline** | Years slam in with a spring + 3D turn, each year's event drawn on as line art, closing line | Number/year is the anchor that survives every cut |
| 5 | **Data drop** | Real dataset as physical objects (marbles, coins, bars that fall) with sound per item | Count is the hook; physics makes it watchable |
| 6 | **Product in 3 steps** | Problem → what it does → how (3 steps) → proof → CTA, 5 scenes, ≤ 30 s | Rebuilt UI morphs: button → window → result |
| 7 | **Showreel flex** | "Show what an incredible motion designer you are" for brand X: research it, go all out, compose the score | Kinetic type + UI as material; bursts and rests |
| 8 | **Style per beat** | Each explanation in a radically different style (self-referential recursion explainer) | The style switch IS the cut; one character/word carries across |
| 9 | **Crafted-medium short** | Hand-drawn stop-motion, paper cut-out shadow theatre, claymation on twos, crayon + watercolor | Texture and a character carry; low fps reads as craft |
| 10 | **Machine / Rube Goldberg** | A tabletop machine where each part knocks the next | Contact moves (impact, hop) + one SFX per hit |
| 11 | **Repo / concept map** | What it is → why useful → a beautiful map of the parts → walk through one path | Camera flies over one map; zoomThrough into each part |
| 12 | **Anti-version** | "The worst possible motion design" / deliberately painful — comedy | Only as a meme; still needs timing |

## What the best prompts have in common
- One sentence of concept that a stranger could repeat ("every note comes from a visible collision").
- A hard constraint (length, aspect, "no video model", "one HTML file") and a named feel ("snappy futuristic", "paper cut-out").
- Sound made from the visuals (collision-synced clinks, foley on every action), not a stock bed.
- Real data or the real product as material; no invented UI.
- Length 15–60 s; 9:16 for social; 3D only when the subject is physical.
